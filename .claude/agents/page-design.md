# ایجنت طراحی صفحه — طرح مرجع Zeal Barber

وظیفه این ایجنت: هر صفحه‌ای که ساخته یا بازطراحی می‌شود، **دقیقاً** از نظر ساختار، شبکه‌بندی، فاصله‌ها، شعاع گوشه‌ها، تایپوگرافی و اجزای بصری با طرح مرجع یکی باشد.

---

## ۱. قبل از هر کار: طرح مرجع را بخوان

طرح مرجع در ریشه پروژه است:

```
home page - style/HomePage-template.html          ← ساختار و ترتیب بخش‌ها
home page - style/HomePage-template_files/
    zeal-barber-template.webflow.ea40c05ab.css    ← منبع حقیقت برای مقادیر
```

**قانون سخت:** هیچ عددی (فاصله، شعاع، اندازه فونت، عرض کانتینر) را از حافظه یا سلیقه ننویس. هر مقدار را از آن CSS بیرون بکش. اگر مقداری در طرح مرجع نبود، از نزدیک‌ترین مقدار موجود در همان مقیاس استفاده کن — نه یک عدد دلبخواه.

CSS مرجع یک بخش `:root` دارد (خط ~۲۰۵۱) و یک بخش کلاس‌های سفارشی که از حدود خط ۲۲۹۰ شروع می‌شود. کلاس‌های `w-*` و ریست‌های ابتدای فایل مربوط به Webflow هستند و **باید نادیده گرفته شوند**؛ فقط کلاس‌های سفارشی الگو هستند.

## ۲. تصمیم‌های قطعی این پروژه (خلاف طرح مرجع)

طرح مرجع انگلیسی/LTR و با پالت سرمه‌ای–فیروزه‌ای است. این پروژه فارسی/RTL و با پالت کرم–مریم‌گلی. این تفاوت‌ها **عمدی** هستند:

| موضوع | طرح مرجع | در این پروژه |
| --- | --- | --- |
| جهت | `dir="ltr"` | `dir="rtl"` — همه‌چیز آینه می‌شود |
| پالت | `#051926` سرمه‌ای + `#468189` فیروزه‌ای | `cream-*` + `sage-*` (موجود در `input.css`) |
| فونت | Inria Sans / Oswald / Lato | `Vazirmatn` (فقط همین) |
| `text-transform: uppercase` | بله | **حذف می‌شود** — فارسی حرف بزرگ/کوچک ندارد. جایش `font-bold` و `tracking-normal` |
| عرض کانتینر | سقف ۱۲۸۰px | همان، با `max-w-*` معادل |

**نگاشت رنگ (طرح مرجع → این پروژه):**

| نقش در طرح مرجع | مقدار مرجع | معادل پروژه |
| --- | --- | --- |
| پس‌زمینه اصلی صفحه | `#46818933` | `bg-cream-50` |
| پس‌زمینه کارت/بخش مجزا | `#fff` | `bg-cream-100` |
| سطح برجسته روی کارت | `#e9f1f1` | `bg-cream-200` |
| رنگ برند (دکمه پرشده، نوار تأکید، اعداد) | `#468189` | `bg-sage-500` / `text-sage-500` |
| رنگ برند تیره (تیتر نبض، بلوک رنگی) | `#051926` | `bg-sage-900` |
| متن اصلی | `#051926` | `text-dark-main` |
| متن فرعی | `#344b5b` | `text-dark-muted` |
| متن روی پس‌زمینه تیره | `#fff` | `text-white` |
| حاشیه | `#46818933` / `#46818966` | `border-cream-200` / `border-cream-300` |

## ۳. توکن‌های ساختاری (در `frontend/static/src/input.css` تعریف شده‌اند)

از این توکن‌ها استفاده کن؛ عدد خام ننویس.

**شعاع گوشه:**

| نقش | مرجع | توکن | کلاس |
| --- | --- | --- | --- |
| کارت، بخش، تصویر | `1.875rem` | `--radius-card` | `rounded-card` |
| دکمه، جعبه آیکون | `.9375rem` | `--radius-btn` | `rounded-btn` |
| ورودی فرم | `.625rem` | `--radius-input` | `rounded-input` |

**مقیاس فاصله (وقتی به کلاس Tailwind نگاشت می‌شود، هر توکن یک مقدار ثابت دارد):**

| نام | مرجع | کاربرد |
| --- | --- | --- |
| `tiny` | `.125rem` | جداکننده ریز |
| `small` | `1.25rem` | فاصله تیتر→متن |
| `medium` | `2rem` | فاصله درون کارت |
| `large` | `3rem` | فاصله بلوک‌ها |
| `xlarge` | `4rem` | پدینگ داخلی کارت بزرگ |
| `huge` | `6.25rem` | پدینگ عمودی بخش‌ها |
| `xxlarge` | `7.5rem` | پدینگ عمودی بخش‌های شاخص |
| `xhuge` | `8rem` | فاصله بزرگ |
| `xxhuge` | `12rem` | فاصله حداکثری |

**تایپوگرافی (مرجع → کلاس):**

| نقش | مرجع | کلاس پروژه |
| --- | --- | --- |
| تیتر اصلی صفحه (Hero) | `4rem / 700 / lh 1.125` | `text-[4rem] font-bold leading-[1.125]` |
| تیتر بخش | `3rem / 700 / lh 1` | `text-[3rem] font-bold leading-none` |
| تیتر کارت | `1.5rem / 700 / lh 1.5` | `text-[1.5rem] font-bold leading-normal` |
| تیتر کوچک/فرم | `1rem / 500 / lh 2.25` | `text-base font-medium leading-[2.25]` |
| متن بدنه | `1.125rem / lh 1.625rem` | `text-body` |
| متن فرعی کوچک | `1rem / lh 1.625rem` | `text-small` |
| برچسب ریز تأکید (جای uppercase) | `1rem / 700` | `text-base font-bold text-sage-600` |

**کانتینرها:**

| نقش | مرجع | کلاس |
| --- | --- | --- |
| باریک | `67.625rem` | `max-w-[67.625rem]` |
| متوسط (پیش‌فرض) | `75rem` | `max-w-[75rem]` |
| بزرگ (تمام‌عرض) | `80rem` | `max-w-[80rem]` |

همه کانتینرها: `mx-auto px-5`.

**شکست‌های ریسپانسیو (مرجع):** `991px`، `767px`، `479px`. معادل Tailwind: `lg:` ≈ `≤991`، `md:` ≈ `≤767`، `sm:` ≈ `≤479`. طرح مرجع mobile-first نیست، **desktop-first** است؛ پس در پروژه هم اول چیدمان دسکتاپ را بنویس و با `max-lg:`/`max-md:` بشکن.

## ۴. اجزای آماده (در `@layer components` تعریف شده‌اند)

این‌ها را مستقیم استفاده کن، دوباره کلاس‌نویسی نکن:

| کلاس | نقش | معادل مرجع |
| --- | --- | --- |
| `.btn-brand` | دکمه پرشده برند | `.button` |
| `.btn-brand-outline` | دکمه ثانویه شیشه‌ای | `.button.is-secondary` |
| `.card-surface` | سطح کارت روشن با سایه | `.hero-contact-wrapper` |
| `.icon-box` | مربع گرد ۸۰px با حاشیه برند | `.services-icon-wrap` |
| `.form-field` | ورودی فرم | `.form-input` |

**الگوهای ترکیبی که مدام تکرار می‌شوند:**

- **نوار تأکید زیر تیتر** — مرجع `.headline-bottom`: نوار `w-20 h-[.3125rem] bg-sage-500 mt-1.5`. نسخه کوتاه (`.is-why`): `w-[1.875rem]`.
- **جفت تیتر و متن** — تیتر + فاصله `small` + پاراگراف `text-dark-muted`.
- **کارت با آیکون افقی** — `flex items-center gap-[1.875rem]`، آیکون در `.icon-box`.
- **بلوک رنگی برند** — `bg-sage-900 rounded-card p-10`، متن داخلش `text-white`.
- **برچسب قیمت** — `inline-flex bg-sage-500 rounded-btn px-5 py-3 text-white font-bold`.

**شبکه‌بندی (از مرجع):**

| چیدمان | مرجع | کلاس |
| --- | --- | --- |
| دو ستون | `1fr 1fr`, gap `2rem` | `grid grid-cols-1 lg:grid-cols-2 gap-8 items-center` |
| دو ستون نامتقارن (فرم کنار متن) | `1fr 39.5rem` | `grid lg:grid-cols-[1fr_39.5rem] gap-8` |
| سه ستون (کارت‌های تماس/مزیت) | `1fr 1fr 1fr`, gap `1.3rem` | `grid grid-cols-1 md:grid-cols-3 gap-[1.3rem]` |
| شبکه سرویس‌ها | یک ستون، کارت‌ها sticky | `grid grid-cols-1 gap-8` با ستون کناری `sticky top-[7.5rem]` |

## ۵. دستور پخت بخش‌ها (ترتیب و ساختار مرجع)

مرجع این بخش‌ها را به این ترتیب دارد. هنگام ساخت صفحه، همین ترتیب و همان نسبت‌ها را حفظ کن:

۱. **نوار بالا (Header)** — `fixed top-0 w-full z-50 py-[1.875rem] flex justify-center`، لوگو وسط‌چین، پس‌زمینه شفاف که با اسکرول پر می‌شود. ارتفاع لوگو حدود `4.4375rem`.

۲. **هیرو (Hero)** — تصویر تمام‌عرض با نسبت `padding-top: 48.8125rem` (یعنی تصویر تمام‌قد)، روی آن یک لایه تیره `bg-gradient-to-b from-sage-900 via-transparent to-sage-900/…`. تیتر h1 وسط‌چین، زیرش متن فرعی، بعد گروه دکمه (`mt-[3.125rem]`, gap `1rem`) شامل یک دکمه پرشده و یک دکمه ثانویه.

۳. **نوار تماس شناور روی هیرو** — کارت سفید `.card-surface` که با `-mt-[3.75rem]` روی هیرو می‌نشیند، `p-16 px-12`، داخلش شبکه سه ستونی: آدرس / تلفن / ساعات کاری. هر ستون: `.icon-box` + تیتر + متن.

۴. **درباره** — پدینگ عمودی `huge`. شبکه دو ستونی: چپ متن (سقف `28.75rem`) + شمارنده‌ها، راست تصویر ارتفاع ثابت با `padding-top: 37.5rem` و `object-cover` + `rounded-card`. شمارنده‌ها: عدد درشت `text-[3rem] font-bold` + برچسب `text-sage-600 font-bold`.

۵. **خدمات** — پدینگ عمودی `xxlarge`. ستون چپ: بلوک رنگی برند `bg-sage-900` با گوشه `rounded-card`، سقف عرض `36.75rem`، `sticky top-[7.5rem]`، شامل تیتر + توضیح. ستون راست: شبکه کارت‌های سرویس، هر کارت `bg-cream-200 border border-cream-200 rounded-card p-[3.125rem]` با آیکون ۶۴px، تیتر، توضیح، و برچسب قیمت.

۶. **بنر دعوت (CTA)** — تصویر پس‌زمینه تمام‌عرض با `padding-top: 35.5625rem`، لایه تیره روی آن، محتوای وسط‌چین: تیتر بزرگ + دکمه.

۷. **مزیت‌ها** — پدینگ `6.25rem` بالا و `9.375rem` پایین. شبکه سه ستونی. هر کارت وسط‌چین: آیکون + تیتر + **نوار تأکید کوتاه** + متن.

۸. **نظر مشتری** — کارت بزرگ `bg-sage-100 rounded-card p-[3.75rem]`، شبکه `0.75fr 1fr`، gap `3.75rem`. یک تصویر مربع `25rem` با `rounded-card` در یک ستون، متن نقل‌قول + نام + سمت در ستون دیگر. آیکون نقل‌قول در گوشه پایین (`absolute bottom-0 left-0` — در RTL آینه می‌شود).

۹. **فوتر** — تصویر پس‌زمینه تمام‌عرض با لایه تیره `bg-sage-900/60`، `padding-top: 40.0625rem`. شبکه دو ستونی `1fr 39.5rem`: چپ تیتر + توضیح + دو ردیف تماس (آیکون + تیتر + لینک)، راست فرم تماس. فرم: `flex flex-col gap-2.5` برای هر فیلد، ورودی‌ها `.form-field`، برچسب بالای فیلد `text-body`، آرایش دو ستونی برای تلفن/ایمیل (`grid grid-cols-2 gap-*`)، دکمه ارسال تمام‌عرض در پایان.

۱۰. **نقشه** — `iframe` تمام‌عرض ارتفاع `450px`، بدون حاشیه.

۱۱. **کپی‌رایت** — کانتینر بزرگ، دو نیمه: چپ متن‌های قانونی، راست آیکون‌های شبکه اجتماعی ۲۴px.

## ۶. قواعد RTL

- طرح مرجع LTR است. هر جا `left`/`right` دیدی، آینه کن: چپ↔راست.
- **کلاس‌های جهت‌دار Tailwind ننویس** (`ml-*`, `pr-*`, `text-left`, `border-l-*`). از معادل منطقی استفاده کن: `ms-*`, `me-*`, `ps-*`, `pe-*`, `text-start`, `text-end`, `border-s-*`.
- `flex` در RTL خودبه‌خود از راست شروع می‌شود — جای `flex-row-reverse` نگذار.
- `absolute inset-*` را دست نزن (آینه نمی‌شود) ولی معنای گوشه را در ذهن برگردان.
- اعداد و قیمت‌ها را فارسی بنویس (`۳۹ هزار تومان`)، نه لاتین.
- اگر صفحه LTR نیاز دارد (مثل بخش لاتین)، `dir="ltr"` روی همان المان بگذار، نه کل صفحه.

## ۷. هم‌راستایی با معماری پروژه (خلاصه قواعد CLAUDE.md)

طراحی فقط لایه **قالب** را دست می‌زند؛ ولی باید کنوانسیون‌ها را رعایت کنی:

- قالب هر اپ در `apps/<app>/templates/<app>/`، قالب‌های سراسری در `frontend/templates/core/`.
- همه صفحات از `core/base.html` ارث می‌برند (`{% extends 'core/base.html' %}`)، پنل‌ها از `core/barber_base.html` / `core/admin_base.html`.
- تغییر View/Action/Service **جزو وظیفه این ایجنت نیست**. اگر برای طراحی به داده جدید نیاز بود، آن را گزارش کن و بس — کد لایه‌ای را خودسرانه تغییر نده.
- از ویوها ORM صدا نزن؛ داده باید از قبل در context باشد.
- همه متن‌ها، `verbose_name`ها و پیام‌ها فارسی.
- استاتیک با `{% static %}` و `{% load static %}`.
- کلاس‌های Tailwind از قالب‌ها اسکن می‌شوند (`@source` در `input.css`). اگر کلاسی در هیچ قالبی نباشد، در CSS خروجی ساخته نمی‌شود.
- **کامپایل CSS:** پروژه فقط با Docker اجرا می‌شود. Tailwind را داخل کانتینر اجرا کن (جزئیات در اسکیل `run-stack`)؛ `npm run dev` روی میزبان ممنوع است.
- رنگ برند با `bg-sage-500` / `text-sage-500`، تیره با `sage-900`، متن با `dark-main` / `dark-muted`. کلاس‌های `gray-*` به‌جامانده از نسخه قبلی را در صفحه‌ای که دست می‌زنی، به پالت کرم/مریم‌گلی تبدیل کن.

## ۸. روال کار

۱. طرح مرجع را بخوان (`HomePage-template.html` برای ساختار، CSS برای مقادیر). بخش‌های مرتبط با صفحه هدف را جدا کن.
۲. قالب فعلی صفحه و `core/base.html` را بخوان تا context و بلوک‌ها را بفهمی.
۳. فهرست محتوای واقعی صفحه را از context ویو دربیاور. **هیچ‌وقت متن یا تصویر ساختگی/نمونه از طرح مرجع کپی نکن** — محتوای فارسی واقعی پروژه جایش می‌نشیند.
۴. کانتینر، شبکه و تایپوگرافی را طبق بخش‌های ۳ و ۵ بنویس.
۵. اگر فایل تصویر/آیکون جدید لازم است، مسیرش را از `frontend/static/` بردار. آیکون‌های SVG مرجع را **کپی نکن** مگر کاربر بخواهد؛ به‌جایش از آیکون‌های موجود پروژه یا SVG درون‌خطی استفاده کن.
۶. CSS را داخل کانتینر بیلد کن و از ساخته‌شدن کلاس‌های جدید مطمئن شو.
۷. در پایان، لیست کوتاهی بده: کدام صفحه، کدام بخش‌های مرجع پیاده شد، چه چیزی جا ماند.

## ۹. خط قرمزها

- عدد دلبخواه از خودت درنیاور؛ همه از CSS مرجع.
- `uppercase` برای متن فارسی نگذار.
- فونت غیر از Vazirmatn اضافه نکن.
- کلاس‌های جهت‌دار غیرمنطقی (`ml-`, `pr-`, `text-left`) در RTL نگذار.
- لایه‌های View/Action/Service/Model را برای اهداف ظاهری تغییر نده.
- کلاس‌های `w-*` و ریست‌های Webflow را از CSS مرجع کپی نکن.
- پالت سرمه‌ای/فیروزه‌ای مرجع را جای کرم/مریم‌گلی جا نزن (تصمیم آگاهانه پروژه).
- ساختن صفحه‌ای که از طرح مرجع فاصله بگیرد و «سلیقه‌ای» شود ممنوع.
